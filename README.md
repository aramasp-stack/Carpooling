# TransportApp — попутчики по маршрутам Еревана

Сервис продаёт места в машинах частных водителей, которые ездят по заранее заданным маршрутам Еревана. Маршрут — это начальная и конечная точки, без промежуточных остановок: где подсадить пассажира по пути, водитель и пассажир договариваются сами. Оплата только картой. Платформа удерживает комиссию и госпошлину онлайн-платформы (4%) и раз в неделю выплачивает остальное водителю.

Как у Яндекса (Яндекс Go и Яндекс Про), приложений два: для пассажира и для водителя.

- Техническое задание: [docs/TZ.md](docs/TZ.md) (рабочая версия — в Claude Docs).
- Мобильные приложения (Flutter, Android и iOS): папки [apps](apps) и [packages](packages).
- Веб-прототип (этап 1 ТЗ): папка [prototype](prototype).

## Мобильные приложения

Один код на Flutter для Android и iPhone. Карта — официальный [Яндекс MapKit для Flutter](https://yandex.ru/maps-api/docs/mapkit/flutter/generated/getting_started.html).

| Папка | Что это |
| --- | --- |
| `apps/passenger` | Приложение пассажира |
| `apps/driver` | Приложение водителя (демо-водитель — Арам) |
| `packages/core` | Общее ядро на Dart: маршруты, расписание, места, брони, деньги, поиск; тесты |
| `packages/ui` | Общий интерфейс: Яндекс Карта с пробками, схема салона, карточки |

Пока нет сервера, каждое приложение хранит данные на своём телефоне; общими между телефонами они станут после подключения Supabase.

### Сборка и запуск (Windows)

Нужны Flutter, Android SDK и JDK 21 (её требует модуль Яндекс MapKit; указать Flutter: `flutter config --jdk-dir <папка JDK 21>`). Ключ «MapKit – мобильный SDK» из [кабинета разработчика Яндекса](https://developer.tech.yandex.ru/) передаётся при сборке; без ключа приложение работает, но вместо карты показывается заглушка.

Ключ хранится в файле `mapkit.json` в корне проекта; git его не сохраняет. Скопируйте `mapkit.example.json` в `mapkit.json` и впишите ключ, затем:

```bash
cd apps/passenger
flutter run --dart-define-from-file=../../mapkit.json
```

Проверка ядра:

```bash
cd packages/core
dart test
```

Сборка для iPhone возможна только на Mac — для этого используем облачную сборку (Codemagic) и аккаунт Apple Developer.

## Прототип

| Адрес | Что это |
| --- | --- |
| `prototype/` | Оба приложения рядом в рамках телефонов |
| `prototype/passenger/` | Приложение пассажира |
| `prototype/driver/` | Приложение водителя |

Оба приложения работают с одними рейсами: бронь в приложении пассажира появляется у водителя, а рейс, созданный водителем, сразу виден в поиске у пассажира. Данные хранятся только в браузере.

**Пассажир:**

- Яндекс Карты с пробками; при открытии карта без маршрутов;
- после «откуда» появляются маршруты рядом, после «куда» остаётся один маршрут и список водителей на нём;
- точку можно ввести текстом, выбрать на карте или взять своё местоположение;
- схема салона: у каждого места своя цена, занятые отмечены; одна итоговая сумма;
- демо-оплата картой, отмена по правилу 60 минут, слежение за машиной, оценка водителя.

**Водитель (демо-водитель — Арам):**

- свои рейсы по дням, занятость мест и доход за каждый рейс;
- новый рейс: маршрут, день, время, какие места продавать и цена каждого места;
- рейс: пассажиры и где их ждать, отметки «сел / не пришёл», звонок через подменный номер (демо);
- начать рейс (симуляция движения с подсказками, кого подобрать) и завершить рейс;
- заработок: к выплате в понедельник, разбивка по рейсам (комиссия 10% — пример, госпошлина 4%);
- профиль: документы, карта для выплат, принятая оферта.

### Ключ Яндекс Карт

Без ключа видны карта и пробки, но маршруты строятся упрощённо (через публичный сервер OSRM), а адреса ищутся только по списку известных мест. С ключом маршруты строит Яндекс с учётом пробок и работает поиск любых адресов.

1. Откройте [кабинет разработчика Яндекса](https://developer.tech.yandex.ru/) и войдите.
2. «Подключить API» → «JavaScript API и HTTP Геокодер» → получите ключ.
3. В настройках ключа ограничьте его своими адресами (HTTP Referer), например `localhost` и адрес сайта.
4. Вставьте ключ в [prototype/config.js](prototype/config.js): `yandexApiKey: "ваш-ключ"`.

Бесплатный ключ подходит только для прототипа. Условия Яндекса запрещают в бесплатной версии отслеживать транспорт в реальном времени, поэтому для запуска сервиса нужна коммерческая лицензия.

### Запуск

```bash
python -m http.server 8000 --directory prototype
```

Затем откройте http://localhost:8000 в браузере.

### Посмотреть на телефоне

- **GitHub Pages:** в настройках репозитория → Pages → Deploy from a branch → ветка `feature/prototype`, папка `/ (root)`. Через минуту прототип откроется по адресу https://aramasp-stack.github.io/Carpooling/prototype/passenger/ (пассажир) и `.../prototype/driver/` (водитель). На телефоне их можно добавить на главный экран как приложения.
- **По Wi-Fi:** запустите сервер на компьютере и откройте на телефоне `http://<IP компьютера>:8000/passenger/` (телефон и компьютер в одной сети; Windows может спросить разрешение для Python в брандмауэре).
