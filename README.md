# TransportApp — поездки по маршрутам Еревана

Сервис продаёт места в машинах частных водителей, которые ездят по заранее заданным маршрутам Еревана. Оплата только картой. Платформа удерживает комиссию и госпошлину онлайн-платформы (4%) и раз в неделю выплачивает остальное водителю.

- Техническое задание: [docs/TZ.md](docs/TZ.md) (рабочая версия — в Claude Docs).
- Прототип (этап 1 ТЗ): папка [prototype](prototype).

## Прототип

Что умеет:

- карта Еревана и 4 демо-маршрута;
- поиск «откуда — куда» на 3 дня вперёд, остановку можно выбрать на карте;
- бронь 1–4 мест с демо-оплатой картой (деньги не списываются);
- разбивка цены: водителю, комиссия 10% (пример), госпошлина 4%;
- отмена: бесплатно раньше чем за 60 минут, позже — без возврата;
- симуляция движения машины по маршруту, время до остановки, оценка водителя.

Брони хранятся только в браузере. Координаты остановок и цены условные.
Линии маршрутов строит публичный демо-сервер OSRM; без связи с ним линии рисуются прямыми.

### Запуск

```bash
python -m http.server 8000 --directory prototype
```

Затем откройте http://localhost:8000 в браузере.
